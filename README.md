# code_wars_solutions
Documenting my Python learning curve on CodeWars. First tries, refactored code, and better logic I stole—err, learned—from top solutions! :)

Instead of wading through endless textbook theory, I decided the best way to learn Python was to jump straight into the deep end with random CodeWars challenges. (A totally deliberate, highly strategic move... absolutely ;p).

After a healthy amount of Googling and trial-by-fire, I started piecing together basic syntax 6–7 Katas in. This repo tracks my raw attempts alongside the cleaner logic I picked up along the way.
